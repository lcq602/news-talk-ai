# 00 · 产品愿景、用户与范围

状态：v0.1 / 2026-11-12 / 工作假设，不代表已完成用户验证。

## 一句话定位
通过**真实英文新闻或获授权的新闻材料**，引导英语学习者完成有目标的阅读、英文讨论、表达反馈和间隔复习。

## 要解决的痛点
- 只读新闻：单词查了很多，却不会开口组织观点。
- 只找 AI 聊天：缺少具体话题，重复“你好/今天做什么”，学习过程碎片化。
- 传统纠错：每句都指出错误会打断思路，产生表达焦虑。
- 单词收藏：没有复习和迁移运用，难形成长期掌握。
- 新闻太难：背景知识、新闻文体和原始词汇难度超过学习水平。

## 目标用户 / 典型画像
- 核心：中文母语、A2–B2 学习者，希望提高英语阅读和实际交流；关心科技、商业、社会新闻。
- 延伸：B2–C1 用户，希望练习讨论复杂观点、概括与反驳。
- 暂不覆盖：零基础拼读教学、考试专项题库、少儿监护学习流程。

## Job-to-be-done
“当我想了解一条感兴趣的新闻时，我希望顺便学会用英语复述、评论它，不需要另找老师/话题，并能记住今天用过的表达。”

## 北极星指标（工作假设）
每周完成**有效学习闭环**的用户数：一次闭环至少包含阅读活动 + ≥3 个与文章有关的有效英语回答 + 生成总结。仅作为产品指标，不等同语言能力确有提高。

辅助指标：首轮 AI 回复成功率、一次会话英文回答数、7 日回访、复习完成率、每闭环模型成本、用户主观纠错有用率。

## MVP 产品原则
1. 先可读可聊：桌面 Web 优先，手机自适应。
2. 新闻来源与展示/输入给 AI 的许可**分开判断**。
3. 教练不是改卷老师：提问、倾听、适度纠错、鼓励扩展思考。
4. 给学习者自主权：难度、纠错频率、中文辅助开关、话题。
5. 小模型优先，但任何模型都不能擅自捏造文章事实。

## 不做（MVP 明确排除）
实时语音陪练、口音评分、社交排名、多用户实时房间、自动翻译整篇受版权保护的新闻、所有网站的全文爬取、复杂多 Agent、多语言学习、商业付费。

## 成功 / 失败信号
- 成功：目标用户能在 10–15 分钟完成一次闭环；用户愿意次日再次阅读；反馈自然且可用于下次复习。
- 失败：用户只看文章不发言、AI 始终泛泛闲聊、新闻内容权利不清、单次交互成本不受控。
