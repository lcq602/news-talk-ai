# 02 · NewsTalk AI 产品需求文档（PRD）

版本 v0.1（2026-11-12） | 状态：提案 / 待实现

## 1. 产品目标
用户每天用 10–15 分钟，在自己感兴趣的一条英文新闻（或获许可的教学文本）上，完成阅读、理解、英文讨论、表达改进、词汇记忆。

## 2. 用户角色
- 游客：浏览公开的教学样例、体验有限对话（应限流）。
- 注册学习者：保存偏好、词汇、会话及学习进度。
- 管理员：管理内容源、许可审核、违规内容和异常成本。

## 3. 信息架构
首页 Discover / 阅读 Reader / 对话 Tutor / 生词本 Vocabulary / 学习回顾 Progress / 设置 Settings。MVP 可将阅读与对话合在同一页，减少跳转。

## 4. 用户故事、优先级、验收标准

### P0 · 新闻发现
US-01：作为学习者，我能按科技/商业/社会等主题浏览合法可展示的新闻索引，并查看标题、日期、来源和外链。
验收：列表可分页、去重、过滤；明确标示“原站链接”；无正文许可时不展示全文；加载/失败/空状态清晰。

### P0 · 阅读器
US-02：我可以在站内阅读获准展示的正文或原创教学短文，选择 A2/B1/B2 级辅助。
验收：排版清晰、段落可选、阅读进度可保存；没有正文许可时改为来源页面外链及站内合法学习材料，绝不暗中抓取原文。
US-03：我可选择一句话请求解释（仅有处理权文本）。
验收：返回直观中文/英文释义和一条例句；可收藏。

### P0 · AI 文章讨论
US-04：我读完后能开启针对本文的英语对话。
验收：第一问来自文章主题；话题不脱离新闻；流式响应；可停止生成、重试失败回复；支持 10 轮（可配置）以内的上下文窗口。
US-05：我用英语回答时，AI 在不打断话题的前提下给出重要语言反馈。
验收：每轮默认最多 1 个关键纠错；反馈包含原表达、建议表达、原因；用户可设置“少/标准/详细”；AI 不把风格差异误判为绝对语法错误。
US-06：我能查看对话结束总结。
验收：提供 2–3 个本次有价值表达、1–2 个常见问题以及下次话题；不存在错误时不强制编造错误。

### P0 · 系统底座
US-07：用户可以注册、登录、删除个人学习记录；服务端保护 API key 和用户对话。
验收：会话授权校验、基本限流、脱敏日志、删除接口、安全错误信息。
US-08：对话可用常见模型提供商 API，统计 token/费用。
验收：请求超时/重试/限额、每用户每日预算；没有配置 Key 时界面提示，不默默失败。

### P1 · 词汇与记忆
US-09：保存文章或 AI 建议的词/短语、释义、原句、来源链接。
US-10：通过当天/次日/数日的复习卡片进行回忆，用户自评“不会/模糊/会”。
US-11：支持学习等级自选、中文辅助开关，以及每日文章话题偏好。

### P1 · 数据看板
US-12：查看 7/30 天阅读文章数、完成的学习闭环数、对话回合、复习情况。数据不伪装成官方英语水平测评结果。

### P2 · 扩展
Web Speech API 或 STT/TTS 语音练习、用户自带 AI key、浏览器插件、用户自定义新闻源、PWA 离线部分复习。

## 5. 关键页面状态
- Discover：骨架屏/无内容/获取失败/来源受限。
- Reader：正文合法可展示 / 仅索引可见 / 内容删除或授权过期。
- Tutor：准备提问/等待用户/生成中/超时/模型不可用/被限流/生成已停止。
- Vocabulary：空词本/待复习/全部复习完成。
- Progress：无记录/统计正常。

## 6. 非功能需求（目标，不是现有表现）
- 桌面优先，支持窄屏；对话输入不丢失。
- 主要页面常规网络条件下尽量 2 秒内给出可感知状态；AI 首 token 延迟记录 P50/P95。
- 个人数据默认最小化；可删除、可导出。
- 来源可追溯，文章/摘要与模型推论区分清楚；监控失败率和成本。
- Web 无障碍：键盘可达、输入焦点、对比度、屏幕阅读器标签。

## 7. MVP 验收场景
用户选 B1 + Technology → 打开有授权的短文 → 读完点击 Talk about this → AI 问“Why do you think...?” → 用户英文回答 → AI 简短回应并指出一个最重要表达问题 → 追问 → 至少 3 次回答 → 结束并收藏一个表达 → 次日复习卡片出现。

## 8. 商业与合规边界
不能承诺无需许可重发新闻全文、自动抓取收费站点、输出未经验证的新闻真实性断言。产品定位“辅助英语练习”，不是新闻官方转载平台。
