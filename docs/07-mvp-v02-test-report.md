# 07 · Python MVP v0.2：纠错评测、重复错误巩固、分阶段讨论

版本：0.2.0 · 2026-11-12

## 目标与范围
沿用 v0.1 的一篇原创练习文章 + FastAPI + 原生网页 + OpenAI 兼容 Chat Completions 接口；**不增加新闻抓取、登录、数据库、语音或复杂界面**。

### 新增 1：41 条人工标注的纠错测试用例
- 样本：`evaluation/cases.json`
- 覆盖：拼写、语法、用词、表达自然度、逻辑清晰度、原文事实误解，以及 10 条正确、不应强行修改的英文句子。
- 有些自然度判断标为 `optional=true`，允许模型不给风格建议。
- 评测执行器：`scripts/evaluate_tutor.py`；读取真实 `.env` 后用实际模型对每条句子出结果，生成本地 JSON。
- **注意**：评测脚本按“类别是否命中”做粗略计数。不能靠类别命中证明改写正确，也不能把不同但合理的分类视为绝对错误。需人工阅读每一条建议；未来增加逐条人工评分和详细精确率/召回率。
- 模型质量和模型价格未实测：当前环境没有你的 API Key，不能把离线替身回答说成真实纠错成功率。

### 新增 2：本次会话内的重复错误提醒
- `app/coach.py` 负责跟踪模型返回的纠错类别（`grammar`、`spelling`、`word_choice`、`clarity`）。
- 同一类错误建议在一次会话内的至少 2 个独立回答轮次出现，界面提示后续会进行巩固练习，并在下一轮系统消息中告诉模型结合当前文章安排一次短句练习。
- 只按**类别**累计，并不能证明两处错误完全相同。模型可能误判，因此提示明确声明“这是模型分类统计”。
- 自然度建议、事实理解纠正不能作为反复训练语法的依据；避免重复弹窗，同一类别本次会话只提示一次。
- 内存状态，点击新对话或重启服务器即清空，**不支持跨天记忆**。

### 新增 3：阅读理解 → 自由讨论
- 开场 AI 基于文章问一个具体事实问题。
- 前两次学习者回答用于文章理解的热身，AI 对回答进行常规语言纠错；第二次回答后转换为讨论。
- 后续引导表达立场、比较选择、举例、思考现实应用。
- 两个问答不代表用户已掌握文章。当前不做理解正确率的自动评测和适应性晋级。
- 返回 `phase=comprehension|discussion`，在网页上标明所处阶段。

## 使用
```powershell
git pull
uv sync
uv run pytest -q
uv run uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

配置 `.env`：`OPENAI_BASE_URL`、`OPENAI_API_KEY`、`OPENAI_MODEL`，地址后缀是 `/v1`。

单独测试真实模型：
```powershell
# 测前 5 条，避免一次性产生较高费用
uv run python -m scripts.evaluate_tutor --limit 5
# 完整评测：41 条真实模型请求，按供应商计费
uv run python -m scripts.evaluate_tutor
```
输出写入 `evaluation/results.local.json`，已在 `.gitignore` 中排除。输出包含模型纠错文本，不建议公开提交。

## 已知局限与下一个版本
- JSON 格式完全依赖兼容模型遵循提示词，解析失败可重试；缺少自动 JSON 修复。
- 没有真实语法评估器，只能通过人工标注样例检查模型效果。
- 反复错误按类别聚合，可能将两种不同的语法问题合并。下一步考虑按具体语言规则（如主谓一致、情态动词后原形）标注。
- 理解阶段只有固定两个回合，没有可靠的理解能力判断。未来可基于答案与文章信息给证据性反馈。
- 无流式响应/持久化/认证/生产限流，继续仅推荐本地 `127.0.0.1` 运行。
